Sign in to manage your portfolio

This page only works with a GitHub access key that can change the portfolio repository, so nobody else can edit the site. The key stays in this browser and is sent only to GitHub.

How to get an access key (one time, about 2 minutes)
  1. Sign in to GitHub as IbtissamBukhari and open New fine-grained token.
  2. Name it "Portfolio admin" and pick an expiry (for example 1 year).
  3. Under Repository access, choose Only select repositories and select IbtissamBukhari.github.io.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it and paste it above. GitHub shows it only once, so keep it somewhere safe, like a password manager.

The key can only change files in the portfolio repository, nothing else on the account. You can delete it on GitHub at any time.
