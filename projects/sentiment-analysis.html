Explainable Sentiment Analysis

A web app and API that classifies text as positive, neutral or negative with RoBERTa and explains each prediction word by word with LIME. The model is quantised to 8 bits so the whole app runs on a free 512 MB server.

The problem

A sentiment score on its own is hard to trust. People reviewing customer feedback want to know which words drove the label, and a demo is only useful if it can run somewhere cheap. Full transformer models need well over 512 MB of memory, more than free hosting allows.

Approach

  1. Preprocessing experiment. Built a spaCy pipeline that keeps negations such as "not" and "never". RoBERTa scored better on raw text, because cleaning removes context a transformer relies on, so the app sends raw text.
  2. Model selection. Compared Cardiff RoBERTa, a multilingual DistilBERT and a DeBERTa model on real reviews; RoBERTa was the most accurate.
  3. Explainability. LIME removes words at random, re-scores a few hundred variants and fits a simple model to estimate each word's contribution.
  4. Fit it on a small server. Switched to the 8-bit ONNX export of the same model on ONNX Runtime, without PyTorch, and tuned the explanation workload for a single CPU.

The model separates positive from negative reliably. Three-star reviews usually mix praise and complaints, and the model tends to commit to one side; part of this is label noise, since a 3-star rating does not always mean neutral text.

CI runs three jobs on every push: the test suite, a comparison of the quantised model against the original, and a Docker load test under a hard 512 MB memory limit. The app peaked at about 375 MB while serving a prediction, an explanation and a 200-row CSV.

Limitations and next steps

  • Neutral reviews are often misclassified; fine-tuning RoBERTa on product reviews is the most promising next step.
  • The model was trained on tweets, so long or domain-specific text can be less accurate, and inputs over 512 tokens are truncated.
  • LIME explanations are approximate and can vary slightly between runs. English only.
