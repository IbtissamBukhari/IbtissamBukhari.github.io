AI Road Accident Detection

A team final year project at MUST: a system that detects road accidents in video in real time, writes an incident report and sends emergency alerts automatically, so help can be dispatched without waiting for someone to call.

The problem

After a road accident, the time until help is called matters. Cameras already watch many roads, but someone has to notice an accident and report it. This project automates that chain: detect the accident, describe it, and alert the right people.

Approach

  1. Train a detector. Custom-trained YOLOv12 on accident footage for real-time detection from video.
  2. Generate the report. An AI agent using transformer-based language models writes an incident report from the detection.
  3. Alert automatically. The system sends emergency alerts as soon as an accident is confirmed.
  4. Build the backend. FastAPI with JWT authentication, SQLAlchemy and Alembic, automated alerts, a Pytest suite and Docker deployment.

Results

The detector reached 88.6% mAP@50 with 87% precision and 84% recall. mAP@50 counts a detection as correct when its box overlaps the real accident by at least half, averaged across confidence levels.

The code is not public because it is a team university project. I'm happy to walk through it in an interview.
