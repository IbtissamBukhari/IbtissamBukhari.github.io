About

Software engineer by training, ML engineer by choice.

I studied Software Engineering at Mirpur University of Science and Technology, which taught me to treat code as something other people have to run, test and maintain. Machine learning is where I apply that: a model is only useful once it is deployed, explained and checked.

My projects follow the same path. I start with the data and the question, choose the metric that matches the real cost of a mistake, and ship the model as an API with tests, Docker and CI. I care about explainability because the people who use a prediction need to know why it was made.

My final year project detected road accidents from video with YOLOv12 and triggered emergency alerts automatically. Since then I've focused on NLP and MLOps: transformer models, model compression, experiment tracking and deployment.
